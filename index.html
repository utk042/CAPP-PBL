Pharmacy Inventory Computing System

CAPP · CCSE0304 · PBL Group 91 — Progress Review II

Alerts

Raised by AND-masking each medicine's 8-bit status register.

    Stock vs reorder level

    Bar = current units; tick = reorder level. Comparison done by the ALU (SUB → N flag).

    Recent stock movements

    Every sale is an ALU SUB, every purchase an ALU ADD; flags are recorded.

    Arithmetic & Logic Unit design

    8-bit ALU with function select S2 S1 S0. Example: A = units in stock, B = units sold.

    Division — strips from loose tablets

    Tablets ÷ pack size = strips (quotient) and loose tablets (remainder).

    Booth's multiplication (signed)

    e.g. stock change (−ve for returns) × units per pack. Range −127…127.

    Logic operations on the medicine status register

    Selective set (OR), selective clear (AND with mask'), selective complement (XOR) and mask test (AND).

    IEEE 754 — how a price is stored

    Floating point arithmetic, step by step

    Single precision, round-to-nearest-even — e.g. unit price × quantity = stock value.

    PharmaCPU — instruction set & formats

    16-bit instructions, 4-bit opcode, 8 registers, 512-word memory. Inventory records live at 0x100.
